# CCI Plant Monitoring - test download 1.0.9

**Download:** `CCI-Plant-Monitoring-Setup-1.0.9.exe` (click it above, then the Download button), or directly:
https://github.com/Tishkos/applicationCocaCola/raw/setup-test/CCI-Plant-Monitoring-Setup-1.0.9.exe

This branch is only for downloading the Setup by hand: the installed program's updater does not look here (it
reads the branch `setup-download` and the Releases), so nothing installs by itself from this branch.

Install over an earlier version: `CCI-Plant-Monitoring-Setup-1.0.9.exe /S /UPDATE` in an administrator PowerShell, or
double-click it. Settings and history stay. `SHA256SUMS.txt` holds the Setup's SHA-256. Built from branch
`live-dashboard`, commit 9c849b0.
